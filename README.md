## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js compatible with the project's dependencies
- npm
- Git (optional, for cloning the repository)

### 1. Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
```

Replace `YOUR_REPOSITORY_URL` with the actual GitHub repository URL.

### 2. Open the Project Directory

```bash
cd YOUR_PROJECT_FOLDER
```

Replace `YOUR_PROJECT_FOLDER` with the actual directory name.

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open in Your Browser

Visit:

http://localhost:3000

The development server will display the portfolio locally. Changes to supported files will appear during development.

## 🏗️ Production Build

To create an optimized production build, run:

```bash
npm run build
```

To start the production server after a successful build, run:

```bash
npm run start
```

Make sure the corresponding scripts exist in `package.json`.
